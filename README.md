# AI Map + ตัวหาเส้น EMA

เว็บไซต์ 2 หน้าสำหรับดูหุ้นสหรัฐ รันบน GitHub ฟรี อัปเดตเองทุกวัน
ไม่ต้องติดตั้งอะไรในเครื่อง เปิดจากมือถือได้

| แท็บ | ทำอะไร |
|---|---|
| **AI Map** | แผนที่หุ้น AI แบ่งตามธีมธุรกิจ 10 กลุ่ม ดูว่าเงินไหลเข้าธีมไหน |
| **หาเส้น EMA** | หาหุ้นที่ราคากำลังชนเส้น EMA 5/10/20/50/100/200 |

ข้อมูล: S&P 500 + Nasdaq 100 (รวมกันราว 517 ตัว หักตัวซ้ำแล้ว)

## ไฟล์ในโปรเจกต์ (7 ไฟล์)

```
ai-map/
├── build.py                      ← ดึงข้อมูล + คำนวณ เขียนออกเป็น docs/data.json
├── themes.yml                    ← แผนที่ธีม→หุ้น (แก้เองได้)
├── requirements.txt
├── .gitignore
├── .github/workflows/build.yml   ← ตั้งเวลาให้ GitHub รันเองทุกวัน
└── docs/                         ← ตัวเว็บไซต์ (GitHub Pages ชี้มาที่นี่)
    ├── index.html
    ├── style.css
    └── app.js
```

`docs/data.json` โปรแกรมสร้างให้เองตอนรัน ไม่ต้องอัปขึ้นไป

## วิธีขึ้น GitHub

**1. สร้าง repo** — github.com กด **+** มุมขวาบน → **New repository**
ตั้งชื่อ `ai-map` เลือก **Public** → **Create repository**

**2. อัปไฟล์**

ในหน้า repo ว่าง ๆ กด **uploading an existing file** แล้วลาก **โฟลเดอร์ `docs`**
กับไฟล์ `build.py`, `themes.yml`, `requirements.txt` เข้าไป → **Commit changes**

**3. สร้างไฟล์ workflow ด้วยมือ**

โฟลเดอร์ที่ขึ้นต้นด้วยจุดลากขึ้นไม่ได้ เบราว์เซอร์ตัดทิ้งเสมอ ต้องพิมพ์เอง

วาง URL นี้ในช่อง address bar (แทน `<ชื่อผู้ใช้>` ด้วยชื่อของคุณ)

```
github.com/<ชื่อผู้ใช้>/ai-map/new/main
```

ช่องชื่อไฟล์พิมพ์ทั้งบรรทัดนี้ พอพิมพ์ `/` GitHub จะแตกโฟลเดอร์ให้เอง

```
.github/workflows/build.yml
```

เปิดไฟล์ `build.yml` จากในซิปด้วย Notepad → `Ctrl+A` `Ctrl+C` → วางในช่องโค้ด → **Commit changes**

**4. รันครั้งแรก**

แท็บ **Actions** → ถ้ามีปุ่มยืนยันให้กด **I understand my workflows, go ahead and enable them**
→ คลิก **อัปเดตข้อมูลหุ้น** ทางซ้าย → **Run workflow** → กดปุ่มเขียว

รอ 5–15 นาที (ดึงหุ้น 517 ตัว) จนขึ้นติ๊กเขียว

> อยากลองเร็ว ๆ ก่อน ใส่ `60` ในช่อง limit จะเสร็จใน 1–2 นาที
> แล้วค่อยรันใหม่แบบเต็มทีหลัง

**5. เปิดเป็นเว็บ**

**Settings** → เมนูซ้าย **Pages** → Source เลือก **Deploy from a branch**
→ Branch `main` + โฟลเดอร์ **`/docs`** → **Save**

รอ 1–2 นาที จะได้ลิงก์

```
https://<ชื่อผู้ใช้>.github.io/ai-map/
```

บุ๊กมาร์กไว้ในมือถือได้เลย ข้อมูลอัปเดตเองทุกวันจันทร์–ศุกร์ ตอน 21:30 UTC
(ประมาณ 04:30 เช้าเวลาไทย หลังตลาดสหรัฐปิด)

## วิธีใช้เว็บ

### หน้า AI Map

- **ปุ่มช่วงเวลา** 1 วัน / 1 สัปดาห์ / 1 เดือน / 3 เดือน / ต้นปี / 1 ปี — กดแล้วทุกกล่องเปลี่ยนพร้อมกัน
- **กล่องกลุ่ม** เรียงอัตโนมัติจากกลุ่มที่ค่ากลางแรงสุดลงไปหาอ่อนสุด
- **ในกล่อง** ตัวบวกกับตัวลบอยู่ด้วยกัน แยกด้วยสีเขียว/แดง เรียงจากบวกมากสุดลงไปหาลบมากสุด
- **หัวกล่อง** บอกจำนวนตัวขึ้น/ลง และ **ค่ากลาง (median)** ของกลุ่ม
- **ปุ่มแสดง** กรองให้เหลือเฉพาะตัวบวกหรือตัวลบ (ค่ากลางยังคิดจากสมาชิกทั้งหมดเสมอ)
- **คลิกการ์ด** เปิดหน้าต่างรายละเอียด — กราฟราคา 60 วัน, ผลตอบแทนทุกช่วง, ระยะห่างจากทุกเส้น EMA

### หน้าหาเส้น EMA

- **แถบเลื่อน “ระยะที่ถือว่าใกล้”** — หัวใจของหน้านี้ เลื่อนแล้วผลเปลี่ยนทันที
  0.5% = เฉพาะที่ชนแบบเป๊ะ · 3% = มองกว้างขึ้น เจอเยอะขึ้น
- **นับเฉพาะเส้น** — กดปิดเส้นที่ไม่สนใจ เช่นเปิดไว้แค่ 100 กับ 200 เพื่อหาหุ้นที่ย่อมาทดสอบแนวรับใหญ่
- **ชนอย่างน้อย** — ตั้ง 3 ขึ้นไปเพื่อหาจุดที่หลายเส้นมารวมกัน มักเป็นจุดที่ราคาเคลื่อนไหวแรง
- **ตำแหน่งราคา** — เหนือเส้น = ใช้เส้นเป็นแนวรับ · ใต้เส้น = ติดแนวต้าน
- **กรองตามธีม AI** — เลือกธีมจากหน้า AI Map มาดูเฉพาะกลุ่มนั้น
- **การ์ด** ช่องเลข 6 ช่องคือเส้นทั้ง 6 ตัวเลขคือระยะห่างเป็น % (บวก = ราคาอยู่เหนือเส้น)
  **ช่องกรอบเหลืองคือเส้นที่ราคากำลังชน**
- **คะแนน** ชนหลายเส้นยิ่งสูง เส้นยาว (100/200) มีน้ำหนักมากกว่า บวกเพิ่มถ้าเป็นขาขึ้น
- **ปุ่ม CSV** ดาวน์โหลดเฉพาะรายการที่กรองอยู่ตอนนั้น

## แก้ไฟล์ธีม

`themes.yml` คือแผนที่ธีม→หุ้น แก้บน GitHub ได้เลย (คลิกไฟล์ → ไอคอนดินสอ → แก้ → Commit)

```yaml
  - key: ai_chips                    # ชื่อคีย์ ห้ามซ้ำ
    name: ชิป AI / เซมิคอนดักเตอร์   # ชื่อที่แสดงบนเว็บ
    description: คำอธิบายสั้น ๆ
    order: 1                         # ลำดับสำรอง ใช้ตอนค่ากลางเท่ากัน
    tickers: [NVDA, AMD, AVGO]
```

แก้เสร็จไปกด **Run workflow** อีกครั้ง เว็บจะอัปเดตตาม

**กติกา**
- หุ้นตัวเดียวใส่ได้หลายธีม (MSFT อยู่ทั้ง `cloud` และ `ai_software` ได้)
- ใส่ได้เฉพาะหุ้นที่อยู่ใน S&P 500 หรือ Nasdaq 100 ถ้าใส่ตัวที่หลุดดัชนีแล้ว
  จะขึ้นเตือนพร้อมชื่อใน log ของ Actions ไม่ข้ามไปเงียบ ๆ
- ระวัง: ticker ที่เป็น `ON`, `NO` YAML จะตีความเป็น true/false — โค้ดดักไว้แล้ว
  ส่วน `Y`, `N`, `OFF` ถ้าเจอปัญหาให้ใส่เครื่องหมายคำพูด เช่น `"Y"`

## ลองในเครื่องก่อน (ถ้าอยาก)

ไม่จำเป็นเลย แต่ถ้าอยากดูหน้าตาก่อนอัปขึ้น GitHub

```bash
pip install -r requirements.txt
python build.py --demo          # ข้อมูลจำลอง เร็ว ไม่ต้องต่อเน็ต
python -m http.server -d docs 8000
```

แล้วเปิด http://127.0.0.1:8000

> ต้องเปิดผ่าน `http.server` ไม่ใช่ดับเบิลคลิกไฟล์ `index.html` ตรง ๆ
> เพราะเบราว์เซอร์บล็อกการโหลด `data.json` จากไฟล์ในเครื่องด้วยเหตุผลด้านความปลอดภัย

## เหตุผลของการออกแบบ

**ทำไมไม่ใช้ฐานข้อมูลกับเซิร์ฟเวอร์** — GitHub Pages เสิร์ฟได้แต่ไฟล์นิ่ง
งานหนัก (ดึงราคา 517 ตัว + คำนวณ) จึงทำวันละครั้งบน GitHub Actions แล้วเก็บผล
เป็นไฟล์ JSON ไฟล์เดียว เปิดเว็บก็แค่โหลดไฟล์นั้นแล้วกรองในเบราว์เซอร์
ผลคือเปิดติดทันที ไม่มีค่าใช้จ่าย ไม่มีเซิร์ฟเวอร์ให้ดูแล

**ทำไมกรองในเบราว์เซอร์** — แถบเลื่อนระยะ EMA ต้องตอบสนองทันทีถึงจะใช้งานสนุก
ถ้าต้องยิงกลับไปคำนวณที่เซิร์ฟเวอร์ทุกครั้งจะหน่วง จึงส่งระยะห่างของทุกเส้นมาให้ครบตั้งแต่แรก

**ทำไมใช้ median ไม่ใช่ค่าเฉลี่ย** — ค่าเฉลี่ยจะถูกหุ้นตัวเดียวที่วิ่งแรงมากดึงจนเพี้ยน
เช่นกลุ่ม 10 ตัวที่ 9 ตัวนิ่ง แต่ NVDA +25% ค่าเฉลี่ยจะขึ้นไป +2.5% ทั้งที่ภาพรวมกลุ่มไม่ได้ดี
median ทนต่อค่าสุดขั้วแบบนี้

**หุ้นที่ประวัติไม่ครบ** — เช่นเพิ่งเข้าตลาด 3 เดือนแต่เลือกดูช่วง 1 ปี จะไม่ถูกนำมาแสดง
ไม่ใช่คำนวณจากข้อมูลเท่าที่มี เพราะจะทำให้ตัวเลขเทียบกันไม่ได้

## แก้ปัญหาที่เจอบ่อย

**เว็บขึ้นว่าโหลดข้อมูลไม่สำเร็จ** — ยังไม่ได้กด Run workflow หรือ workflow ล้มเหลว
ไปดูที่แท็บ Actions

**Actions ขึ้นติ๊กแดง** — คลิกเข้าไปดูขั้นตอนที่มีเครื่องหมาย ✕
ส่วนใหญ่คือ Yahoo จำกัดการเรียก (rate limit) แก้ด้วยการกด **Re-run all jobs** อีกครั้ง
ถ้ายังไม่ผ่าน ลองใส่ `limit` เป็น `200` เพื่อลดจำนวนหุ้นลง

**ในหน้า Actions ขึ้นเตือน `ไม่อยู่ในดัชนีแล้ว จึงข้ามไป: XXX`** — เป็นการทำงานปกติ
หมายความว่าหุ้นตัวนั้นใน `themes.yml` หลุดจากดัชนีแล้ว หรือแหล่งข้อมูลใช้ชื่อย่ออื่น
(เช่น Fiserv เปลี่ยนจาก FISV เป็น FI) แก้ชื่อใน `themes.yml` หรือลบออก

**Pages ไม่มีตัวเลือก `/docs`** — โฟลเดอร์ `docs` ยังไม่ได้อัปขึ้นไป ตรวจที่แท็บ Code

**เว็บยังแสดงข้อมูลเก่า** — GitHub Pages ใช้เวลา 1–2 นาทีหลัง workflow เสร็จ
ลองรีเฟรชแบบล้างแคชด้วย `Ctrl + Shift + R`

**schedule หยุดทำงานเอง** — GitHub ปิด schedule ของ repo ที่ไม่มีการเคลื่อนไหวเกิน 60 วัน
เข้าไป commit อะไรก็ได้เพื่อปลุกกลับมา

## ข้อจำกัดที่ควรรู้

- **yfinance ไม่ใช่ API ทางการ** เป็นการดึงข้อมูลจากหน้าเว็บ Yahoo
  Yahoo เปลี่ยนอะไรเมื่อไหร่ก็อาจพังได้ ถ้าเจอบ่อยค่อยพิจารณาย้ายไป Alpaca หรือ Stooq
  โค้ดส่วนดึงข้อมูลอยู่ในฟังก์ชัน `fetch_prices()` ของ `build.py` ที่เดียว
- **รายชื่อ Nasdaq 100** ไม่มีไฟล์ทางการฟรี ใช้ชุดข้อมูลสาธารณะที่ดึงจาก Wikipedia
  อาจช้ากว่าประกาศจริงไม่กี่วัน มีแหล่งสำรองไว้ให้แล้ว
- ยังไม่มีข่าว ตัวเลขพื้นฐาน (P/E, ROE) และ Watchlist
