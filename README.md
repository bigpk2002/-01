## วิธีขึ้น GitHub

**1. สร้าง repo** — github.com กด **+** มุมขวาบน → **New repository**
ตั้งชื่อ `ai-map` เลือก **Public** → **Create repository**

**2. อัปไฟล์**

ในหน้า repo ว่าง ๆ กด **uploading an existing file** แล้วลาก **โฟลเดอร์ `docs`**
กับไฟล์ `build.py`, `themes.yml`, `requirements.txt` เข้าไป → **Commit changes**

**3. สร้างไฟล์ workflow ด้วยมือ**

โฟลเดอร์ที่ขึ้นต้นด้วยจุดลากขึ้นไม่ได้ เบราว์เซอร์ตัดทิ้งเสมอ ต้องพิมพ์เอง

วาง URL นี้ในช่อง address bar (แทน `<ชื่อผู้ใช้>` ด้วยชื่อของคุณ)

```
github.com/<ชื่อผู้ใช้>/ai-map/new/main
```

ช่องชื่อไฟล์พิมพ์ทั้งบรรทัดนี้ พอพิมพ์ `/` GitHub จะแตกโฟลเดอร์ให้เอง

```
.github/workflows/build.yml
```

เปิดไฟล์ `build.yml` จากในซิปด้วย Notepad → `Ctrl+A` `Ctrl+C` → วางในช่องโค้ด → **Commit changes**

**4. รันครั้งแรก**

แท็บ **Actions** → ถ้ามีปุ่มยืนยันให้กด **I understand my workflows, go ahead and enable them**
→ คลิก **อัปเดตข้อมูลหุ้น** ทางซ้าย → **Run workflow** → กดปุ่มเขียว

รอ 5–15 นาที (ดึงหุ้น 517 ตัว) จนขึ้นติ๊กเขียว

> อยากลองเร็ว ๆ ก่อน ใส่ `60` ในช่อง limit จะเสร็จใน 1–2 นาที
> แล้วค่อยรันใหม่แบบเต็มทีหลัง

**5. เปิดเป็นเว็บ**

**Settings** → เมนูซ้าย **Pages** → Source เลือก **Deploy from a branch**
→ Branch `main` + โฟลเดอร์ **`/docs`** → **Save**

รอ 1–2 นาที จะได้ลิงก์

```
https://<ชื่อผู้ใช้>.github.io/ai-map/
```

บุ๊กมาร์กไว้ในมือถือได้เลย **ข้อมูลอัปเดตเองทุกวันตอนตี 4 ครึ่งเวลาไทย**
(ประมาณ 1 ชั่วโมงหลังตลาดสหรัฐปิด · เช้าวันอังคาร–เสาร์)

## วิธีใช้เว็บ

### หน้า AI Map

- **ปุ่มช่วงเวลา** 1 วัน / 1 สัปดาห์ / 1 เดือน / 3 เดือน / ต้นปี / 1 ปี — กดแล้วทุกกล่องเปลี่ยนพร้อมกัน
- **กล่องกลุ่ม** เรียงอัตโนมัติจากกลุ่มที่ค่ากลางแรงสุดลงไปหาอ่อนสุด
- **ในกล่อง** ตัวบวกกับตัวลบอยู่ด้วยกัน แยกด้วยสีเขียว/แดง เรียงจากบวกมากสุดลงไปหาลบมากสุด
- **หัวกล่อง** บอกจำนวนตัวขึ้น/ลง และ **ค่ากลาง (median)** ของกลุ่ม
- **ปุ่มแสดง** กรองให้เหลือเฉพาะตัวบวกหรือตัวลบ (ค่ากลางยังคิดจากสมาชิกทั้งหมดเสมอ)
- **ตัวที่วิ่งแรงสุดต่อกลุ่ม** เลือกได้ 5 / 10 / 20 / ทั้งหมด (ค่าเริ่มต้น 10)
  คัดจาก**ขนาดการเปลี่ยนแปลง** ไม่ว่าขึ้นหรือลง แล้วเรียงจากบวกมากสุดลงไปหาลบมากสุด
  กลุ่มที่มีสมาชิกน้อยกว่าที่เลือกจะแสดงครบทุกตัว
  ปุ่ม **"ดูอีก N ตัวในกลุ่มนี้"** ท้ายกล่องกางดูทั้งหมดได้
  **ค่ากลางและจำนวนขึ้น/ลง คิดจากสมาชิกทั้งหมดเสมอ** ไม่ได้คิดจากแค่ที่แสดง
- **คลิกการ์ด** เปิดหน้าต่างรายละเอียด (ดูหัวข้อถัดไป)

### หน้าหาเส้น EMA

- **แถบเลื่อน “ระยะที่ถือว่าใกล้”** — หัวใจของหน้านี้ เลื่อนแล้วผลเปลี่ยนทันที
  0.5% = เฉพาะที่ชนแบบเป๊ะ · 3% = มองกว้างขึ้น เจอเยอะขึ้น
- **นับเฉพาะเส้น** — กดปิดเส้นที่ไม่สนใจ เช่นเปิดไว้แค่ 100 กับ 200 เพื่อหาหุ้นที่ย่อมาทดสอบแนวรับใหญ่
- **ชนอย่างน้อย** — ตั้ง 3 ขึ้นไปเพื่อหาจุดที่หลายเส้นมารวมกัน มักเป็นจุดที่ราคาเคลื่อนไหวแรง
- **ตำแหน่งราคา** — เหนือเส้น = ใช้เส้นเป็นแนวรับ · ใต้เส้น = ติดแนวต้าน
- **กรองตามธีม AI** — เลือกธีมจากหน้า AI Map มาดูเฉพาะกลุ่มนั้น
- **การ์ด** ช่องเลข 6 ช่องคือเส้นทั้ง 6 ตัวเลขคือระยะห่างเป็น % (บวก = ราคาอยู่เหนือเส้น)
  **ช่องกรอบเหลืองคือเส้นที่ราคากำลังชน**
- **คะแนน** ชนหลายเส้นยิ่งสูง เส้นยาว (100/200) มีน้ำหนักมากกว่า บวกเพิ่มถ้าเป็นขาขึ้น
- **ตัวกรองค่า P/E** — ต่ำกว่า 20 / 20–40 / 40–70 / 70–100 / มากกว่า 100 / ไม่มีค่า
  ใช้หาหุ้นราคาถูกที่กำลังชนเส้น หรือดูว่าหุ้นแพง ๆ กำลังย่อมาถึงแนวรับไหม
  ("ไม่มีค่า" = บริษัทที่ยังขาดทุน จึงคำนวณ P/E ไม่ได้)
- **ค่า P/E แสดงบนการ์ดทุกใบ** พร้อมช่องสถิติ "ค่ากลาง P/E" ของผลที่กรองอยู่
- **เรียงตาม P/E ถูกสุดก่อน** ในเมนูเรียงลำดับ
- **ปุ่ม CSV** ดาวน์โหลดเฉพาะรายการที่กรองอยู่ตอนนั้น

### หน้าเทียบในหมวด

เลือกธีมหรือหมวดธุรกิจ แล้วดูสมาชิกทั้งกลุ่มพร้อมกัน มีสองมุมมอง

**1. ตารางเทียบ** — คอลัมน์ ราคา · วันนี้ · 3 เดือน · 1 ปี · P/E · เกรดงบ ·
รายได้โต · กำไรสุทธิ · มูลค่า · ตำแหน่งเทียบเส้น

ป้าย **ดีสุด** ขึ้นแยกในแต่ละคอลัมน์ **ไม่มีผู้ชนะรวม** เพราะจุดประสงค์คือให้เห็นว่า
ต้องแลกอะไร — ตัวที่โตเร็วสุดมักเป็นตัวที่ P/E แพงสุดด้วย ตัวที่ถูกสุดมักโตช้ากว่า

ด้านบนมีสรุป **ผู้นำแต่ละด้าน** ให้กดข้ามไปดูรายละเอียดได้ทันที

**2. อันดับรวม** — รวม 4 ด้าน ด้านละ 25 คะแนน เทียบกันเฉพาะภายในกลุ่มที่เลือก

| ด้าน | คิดจาก |
|---|---|
| โมเมนตัมราคา | อันดับผลตอบแทน 3 เดือนในกลุ่ม |
| พื้นฐาน | เกรดงบไตรมาสล่าสุด |
| ความถูกเทียบหมวด | P/E เทียบค่ากลางของหมวดตัวเอง |
| เทรนด์เทคนิค | อยู่เหนือ EMA200/50 · เส้นเรียงสวย · รายสัปดาห์เป็นขาขึ้น |

แต่ละใบกางให้เห็นว่าได้คะแนนจากด้านไหนบ้าง

**ข้อจำกัดที่เขียนไว้บนหน้าจอด้วย**

- ทุกตัวเลขเป็น**อดีต** ไม่มีอะไรทำนายอนาคต
- **ยังไม่เคยทดสอบย้อนหลัง**ว่าคะแนนสูงให้ผลตอบแทนดีกว่าจริงหรือไม่
- ไม่ได้ดูข่าว คู่แข่ง ผู้บริหาร หนี้ที่จะครบกำหนด
- ด้าน "ราคาถูก" ให้คะแนน P/E ต่ำ แต่หุ้นถูกมักถูกเพราะมีเหตุผล ต้องหาให้เจอว่าเพราะอะไร

**อันดับ 1 ไม่ได้แปลว่าน่าซื้อที่สุด** แปลว่าเป็นตัวที่ตัวเลขในเว็บนี้ดูดีที่สุดเท่านั้น

## หน้าผลประกอบการไตรมาส

ให้เกรดงบจากตัวเลขที่บริษัท**รายงานแล้ว** แล้วจับคู่กับราคา 3 เดือน

**คะแนนงบ** คิดจาก 4 ตัวชี้วัด อย่างละ 0–2 คะแนน รวมเป็น 8

| ตัวชี้วัด | 2 คะแนน | 1 คะแนน | 0 คะแนน |
|---|---|---|---|
| รายได้เติบโต | ≥ 15% | ≥ 3% | ต่ำกว่า 3% |
| กำไรเติบโต | ≥ 15% | ≥ 0% | ติดลบ |
| อัตรากำไรสุทธิ | ≥ 15% | ≥ 5% | ต่ำกว่า 5% |
| ROE | ≥ 15% | ≥ 7% | ต่ำกว่า 7% |

**เกรด** ดีมาก (6–8) · ดี (4.5–6) · ปานกลาง (3–4.5) · อ่อน (ต่ำกว่า 3)
หุ้นที่มีตัวชี้วัดไม่ถึง 2 อย่างจะไม่ให้เกรด

**การจับคู่งบกับราคา** — จุดที่น่าสนใจที่สุดของหน้านี้

|---|---|

**แถวสั้น 2 บรรทัด** เห็นชื่อ ราคา เกรดงบ และ 3 เดือน · **กดที่แถวเพื่อกางดูตัวเลข 4 ตัว**

**สลับกลับมุมมองเดิม** (จับคู่งบกับราคา 4 ควอดรันต์) ได้ที่ปุ่มบนสุด

## หน้าต่างรายละเอียดหุ้น

คลิกการ์ดหุ้นตัวไหนก็ได้จากทั้งสองหน้า จะเห็น

1. **กราฟราคา 60 วันทำการล่าสุด**
2. **ผลตอบแทนทั้ง 6 ช่วง** — 1 วัน ถึง 1 ปี
3. **ระยะห่างจากเส้น EMA ทั้ง 6 เส้น** พร้อมไฮไลต์เส้นที่ราคากำลังชน
4. **ราคาแพงหรือถูก** — P/E, P/E คาดการณ์, P/BV, P/S
   แต่ละตัวเทียบกับ **ค่ากลางของหุ้นในหมวดธุรกิจเดียวกัน** พร้อมบอกว่าสูง/ต่ำกว่ากี่ %
5. **ตัวเลขกิจการ** — มูลค่าบริษัท, กำไรต่อหุ้น, ROE, อัตรากำไรสุทธิ,
   การเติบโตของรายได้และกำไร, หนี้สินต่อทุน, ปันผล, ค่าความผันผวน (beta), จำนวนพนักงาน
6. **ช่วงราคา 52 สัปดาห์** — แถบแสดงว่าราคาตอนนี้อยู่ตรงไหนระหว่างจุดต่ำสุดกับสูงสุด
7. **มุมมองนักวิเคราะห์** — ราคาเป้าหมายเฉลี่ย, ห่างจากราคาปัจจุบันกี่ %, คำแนะนำรวม
8. **ธีมที่สังกัด**

### ทำไมต้องเทียบกับค่ากลางของหมวด

P/E 30 เท่าเป็นตัวเลขที่ไม่มีความหมายถ้าดูลอย ๆ เพราะหุ้นเทคโนโลยีปกติซื้อขายกันที่
P/E สูงกว่าธนาคารเป็นเท่าตัวอยู่แล้ว ระบบจึงคำนวณค่ากลางของแต่ละหมวดจากหุ้นทั้ง 517 ตัว
ในชุดข้อมูลนี้เอง แล้วบอกว่าหุ้นตัวนี้แพงหรือถูกกว่าเพื่อนในหมวดเดียวกันกี่ %

**ข้อควรระวัง** — อัตราส่วนพวกนี้ดูตัวเดียวตัดสินไม่ได้ หุ้นที่ P/E ต่ำอาจกำลังมีปัญหา
ส่วนหุ้นที่ P/E สูงอาจกำลังโตเร็วจนสมเหตุสมผล ต้องดูคู่กับการเติบโตและคุณภาพกิจการเสมอ
บริษัทที่ขาดทุนจะไม่มีค่า P/E เลย

### ตัวเลขจะสอดคล้องกับราคาที่แสดงเสมอ

ข้อมูลพื้นฐานเก็บไว้ใช้ได้ 7 วัน แต่ราคาอัปเดตทุกวัน ถ้าเอาค่า P/E ที่ Yahoo
ส่งมาตอนดึงมาแสดงคู่กับราคาวันนี้ตรง ๆ ตัวเลขจะไม่ตรงกัน (ราคาขยับ 8% ก็คลาดไป 8%)

ระบบจึงคำนวณอัตราส่วนใหม่ทุกครั้งจากราคาปิดล่าสุด

```
P/E          = ราคาปัจจุบัน ÷ กำไรต่อหุ้น        (กำไรต่อหุ้นเปลี่ยนไตรมาสละครั้ง)
มูลค่าบริษัท  = จำนวนหุ้น × ราคาปัจจุบัน
P/BV, P/S     = ค่าเดิม × (ราคาปัจจุบัน ÷ ราคาตอนดึง)
```

**เอาเครื่องคิดเลขกดตามได้ตรงทุกครั้ง** — ราคาที่แสดงหารด้วยกำไรต่อหุ้นที่แสดง
จะได้ P/E ที่แสดงพอดี

**กรณีหุ้นแตกพาร์** ราคาจะเปลี่ยนกระโดด (เช่นแตก 10:1 ราคาเหลือหนึ่งในสิบ)
เอาอัตราส่วนเก่ามาคูณจะได้ค่าเพี้ยนทันที ระบบจึงเช็กว่าถ้าราคาต่างจากตอนเก็บเกิน 35%
จะซ่อนอัตราส่วนราคาไว้ก่อน ขึ้นข้อความอธิบาย แล้วจัดคิวดึงใหม่ให้เป็นลำดับแรกในรอบถัดไป

### ระบบตรวจสอบตัวเองทุกครั้งที่รัน

ท้ายล็อกของ Actions จะมีบรรทัด `ตรวจความสมเหตุสมผลของข้อมูลพื้นฐาน: ผ่าน`

| `TELEGRAM_CHAT_ID` | เลข Id จากข้อ 2 |

เสร็จแล้วรอบถัดไปจะได้ข้อความอัตโนมัติ **ถ้าไม่ตั้งค่า ระบบจะข้ามไปเงียบ ๆ** ไม่ทำให้อะไรพัง

### ดูข้อความก่อนส่งจริง

```bash
python notify.py --dry
```

อยากแก้เนื้อหาข้อความ แก้ฟังก์ชัน `build_message()` ใน `notify.py`

## หน้าเช้านี้ (หน้าแรก)

รวมสิ่งที่ต้องดูทุกเช้าไว้หน้าเดียว เปิดมาเห็นทันทีไม่ต้องกดข้ามแท็บ

| ส่วน | มีอะไร |
|---|---|
| **ลงแรงวันนี้** | เรียงจากลงหนักสุด พร้อมบอกว่าชนเส้นไหนอยู่ |
| **เพิ่งมาถึงเส้นวันนี้** | เมื่อวานยังไม่อยู่ในระยะ วันนี้เพิ่งเข้ามา |
| **คะแนนรวมสูงสุดทั้งตลาด** | เทียบกันทั้ง 561 ตัว ไม่ต้องเลือกธีมทีละอัน |
| **ที่ติดดาวไว้ วันนี้เป็นยังไง** | โผล่มาเองเมื่อมีหุ้นที่มาร์คไว้ |

**แต่ละใบแสดงครบในที่เดียว** — ราคา · เปลี่ยนแปลงวันนี้ · เส้น EMA ที่ชน ·
เทรนด์ · เกรดงบ · คะแนนรวม · P/E · มูลค่าบริษัท

### "เพิ่งมาถึงเส้นวันนี้" ทำงานยังไง

ตัวที่ชนเส้นค้างมา 5 วันแล้ว กับตัวที่เพิ่งมาถึงวันนี้ มีความหมายต่างกันมาก
ระบบจึงเก็บสถานะของวันทำการก่อนหน้าไว้ในไฟล์ `docs/prev.json` แล้วเทียบทุกรอบ

**เส้นสีเหลือง** = เส้นที่เพิ่งเข้าระยะวันนี้ · **เส้นสีเทาเข้ม** = ชนอยู่แล้วตั้งแต่ก่อนหน้า

ป้าย **เทรนด์เปลี่ยนวันนี้** จะขึ้นเมื่อหุ้นเปลี่ยนจากขาขึ้นเป็นขาลง (หรือกลับกัน) ในวันนั้น

**รอบแรกที่รันจะยังไม่มีข้อมูลส่วนนี้** เพราะไม่มีของเมื่อวานให้เทียบ
รอบถัดไปจะเริ่มแสดงได้ · ถ้ารันซ้ำวันเดิม ระบบจะไม่ทับไฟล์สถานะ
ไม่งั้นข้อมูล "เพิ่งมาถึง" จะหายไปทั้งหมด

### ตัวควบคุม

**ขอบเขต** ทั้งตลาด / เฉพาะหุ้นในธีม AI / เฉพาะที่ติดดาว
**แสดงกลุ่มละ** 5 / 10 / 20

### คะแนนรวมต่างจากแท็บเทียบในหมวดยังไง

| | หน้าเช้านี้ | แท็บเทียบในหมวด |
|---|---|---|
| เทียบกับใคร | **ทั้งตลาด 561 ตัว** | เฉพาะในกลุ่มที่เลือก |
| ใช้ตอนไหน | หาภาพรวมว่าใครเด่นสุด | เทียบตัวเลือกในธีมเดียวกัน |

สูตรเดียวกันทั้งคู่ (4 ด้าน ด้านละ 25) ต่างแค่ขอบเขตที่นำมาจัดอันดับ

**อันดับสูงไม่ได้แปลว่าน่าซื้อ** เป็นแค่ตัวที่ตัวเลขในเว็บนี้ดูดีที่สุด
และทุกตัวเลขเป็นข้อมูลย้อนหลัง

### แท็บย่อย "เรียงตามมูลค่าบริษัท"

อยู่ในหน้าหาเส้น EMA กดแท็บย่อยด้านบนเพื่อสลับ

คัดหุ้นที่ราคาอยู่ในระยะที่ตั้งไว้จาก **เส้น EMA เส้นใดก็ได้** (5 · 10 · 20 · 50 · 100 · 200)
จากทั้ง 561 ตัว **ไม่กรองหมวดหรือธีมเลย** แล้วเรียงตามมูลค่าบริษัทจากใหญ่สุดลงมา

### สองแถบแยกกัน

| แถบ | ใช้ข้อมูล |
|---|---|
| **รายวัน** | EMA รายวัน อัปเดตทุกวันหลังตลาดปิด |
| **รายสัปดาห์** | EMA รายสัปดาห์ อัปเดตสัปดาห์ละครั้ง |

คำนวณคนละชุดกัน หุ้นตัวเดียวอาจเข้าเงื่อนไขแค่ไทม์เฟรมเดียว หัวแถบบอกจำนวนที่เข้าเงื่อนไขทั้งหมด

### ตัวควบคุม

**ระยะที่ถือว่า "แตะเส้น"** ปรับได้ **1.5% ถึง 5%**
ยิ่งกว้างยิ่งเจอเยอะแต่ความหมายจางลง — ที่ 1.5% คือเกือบแตะจริง ที่ 5% คือแค่อยู่ในละแวก

**แถบละ** 10 / 20 / 50 ตัว

### แต่ละใบบอกอะไร

มูลค่าบริษัท (ตัวเลขสีฟ้ามุมขวา) · เส้นที่แตะ · ระยะที่ใกล้ที่สุด ·
ระยะห่างจากทั้ง 6 เส้น (ช่องเหลืองคือเส้นที่แตะ) · ราคา · 1 เดือน · P/E

**เรียงตามมูลค่าเท่านั้น ไม่ได้เรียงตามความน่าสนใจ** บริษัทใหญ่ไม่ได้แปลว่าดีกว่า
และการแตะเส้นไม่ใช่สัญญาณซื้อขาย

## ทดสอบย้อนหลัง (backtest)

ตอบคำถามว่า **สัญญาณในหน้า "น่าจับตามอง" เคยใช้ได้จริงหรือเปล่า**

```bash
python backtest.py            # ใช้ราคาจริง ดึงใหม่ ~3 นาที
python backtest.py --random   # ชุดควบคุม ใช้ราคาสุ่มล้วน
python backtest.py --years 5  # ย้อนหลังกี่ปี
```

ผลเขียนลง `docs/backtest.json` แล้วเว็บจะแสดงตัวเลขข้างชื่อสัญญาณให้เอง
เช่น `ทดสอบแนวรับ EMA200 +1.8%` แปลว่าในอดีต หุ้นที่ติดสัญญาณนี้
ทำได้**ดีกว่าค่าเฉลี่ยหุ้นทั้งหมด 1.8 จุด**เมื่อถือต่ออีก 60 วันทำการ

### กติกาที่ยึด เพื่อไม่ให้หลอกตัวเอง

**1. ไม่แอบดูอนาคต** สัญญาณ ณ วันที่ใด คำนวณจากราคาถึงวันนั้นเท่านั้น

**2. เทียบกับตลาด ไม่ใช่ดูกำไรลอย ๆ** ถ้าตลาดขึ้น 20% แล้วสัญญาณให้ 15%
แปลว่าแย่กว่าไม่ทำอะไร จึงวัดเป็นส่วนต่างจากค่าเฉลี่ยหุ้นทั้งหมดในวันเดียวกัน

**3. ลดการนับซ้ำ** สุ่มตัวอย่างทุก 5 วันทำการ เพราะสัญญาณเดียวกันมักค้างหลายวันติด

**4. ตัวอย่างต้องพอ** น้อยกว่า 100 ครั้งจะขึ้นว่า "ตัวอย่างน้อย" ไม่สรุปผล

**5. ค่า t ต้องเกิน 2** ไม่งั้นขึ้นว่า "ไม่ต่างจากสุ่ม"

### การพิสูจน์ว่าวิธีทดสอบไม่มีอคติ

รัน `--random` จะสร้างราคาสุ่มล้วนที่ไม่มีรูปแบบใดให้จับ
ถ้าวิธีของเราถูกต้อง **ทุกสัญญาณต้องได้ส่วนต่างใกล้ 0**

ผลที่ได้จริง: อยู่ระหว่าง **−0.16% ถึง +0.35%** ทุกสัญญาณ และ |t| ต่ำ
= ไม่มีอคติซ่อนอยู่ ไม่ได้แอบดูอนาคต

**ถ้าสัญญาณไหนทำกำไรได้จากข้อมูลสุ่ม แปลว่ามีบั๊ก** — นี่คือการตรวจที่ควรทำทุกครั้ง
ที่แก้เกณฑ์สัญญาณ

### ข้อจำกัดที่แก้ไม่ได้

- **รายชื่อเป็นสมาชิกดัชนีปัจจุบัน** หุ้นที่เคยอยู่แล้วหลุดออกเพราะผลงานแย่ไม่อยู่ในชุดทดสอบ
  ทำให้ผลดูดีกว่าจริงเล็กน้อย (survivorship bias)
- **ทดสอบได้เฉพาะสัญญาณที่คำนวณจากราคา** สัญญาณ "P/E ต่ำกว่าหมวดแต่ยังขาขึ้น"
  ทดสอบไม่ได้ เพราะมีแต่ P/E ของวันนี้ ไม่มีย้อนหลัง — เอามาใช้กับอดีตจะเป็นการแอบดูอนาคต
- **ไม่คิดค่าคอมมิชชัน ภาษี ส่วนต่างราคาซื้อขาย** ของจริงได้น้อยกว่าที่เห็น
- **ช่วงทดสอบสั้นและเป็นตลาดขาขึ้นเป็นหลัก** ผลอาจต่างไปมากในตลาดขาลง

### อ่านผลยังไง

ตัวเลขที่ได้ **ไม่ใช่คำรับประกัน** เป็นแค่หลักฐานว่าในอดีตช่วงนั้น สัญญาณนี้
เคยตามมาด้วยผลแบบไหน สัญญาณที่ขึ้น "ไม่ต่างจากสุ่ม" ไม่ได้แปลว่าไร้ค่า
อาจแปลว่าตัวอย่างยังไม่พอ หรือมันมีประโยชน์ในแง่อื่นที่ตัวเลขนี้วัดไม่ได้

## แก้ไฟล์ธีม

`themes.yml` คือแผนที่ธีม→หุ้น แก้บน GitHub ได้เลย (คลิกไฟล์ → ไอคอนดินสอ → แก้ → Commit)

```yaml
  - key: ai_chips                    # ชื่อคีย์ ห้ามซ้ำ
    name: ชิป AI / เซมิคอนดักเตอร์   # ชื่อที่แสดงบนเว็บ
    description: คำอธิบายสั้น ๆ
    order: 1                         # ลำดับสำรอง ใช้ตอนค่ากลางเท่ากัน
    tickers: [NVDA, AMD, AVGO]
```

แก้เสร็จไปกด **Run workflow** อีกครั้ง เว็บจะอัปเดตตาม

### เพิ่มหุ้นที่ไม่อยู่ในดัชนี

หุ้นบางตัวยังไม่เข้า S&P 500 หรือ Nasdaq 100 (เช่นเพิ่งเข้าตลาด) ระบบจะไม่ดึงมาให้
ถ้าอยากติดตาม ใส่ชื่อย่อในหัวข้อ `extra` ที่ด้านบนของ `themes.yml`

```yaml
extra: [NBIS, SNDK]
```

ระบบจะดึงราคาและข้อมูลพื้นฐานให้เอง **ชื่อบริษัทกับหมวดธุรกิจเติมให้อัตโนมัติ** ไม่ต้องกรอก

> หุ้นที่เพิ่มที่นี่จะโผล่ในหน้า **หาเส้น EMA** เลย
> แต่ถ้าอยากให้ขึ้นในหน้า **AI Map** ต้องใส่ในรายการ `tickers` ของธีมด้วย

**กติกา**
- หุ้นตัวเดียวใส่ได้หลายธีม (MSFT อยู่ทั้ง `cloud` และ `ai_software` ได้)
- ใส่ได้เฉพาะหุ้นที่อยู่ใน S&P 500 หรือ Nasdaq 100 ถ้าใส่ตัวที่หลุดดัชนีแล้ว
  จะขึ้นเตือนพร้อมชื่อใน log ของ Actions ไม่ข้ามไปเงียบ ๆ
- ระวัง: ticker ที่เป็น `ON`, `NO` YAML จะตีความเป็น true/false — โค้ดดักไว้แล้ว
  ส่วน `Y`, `N`, `OFF` ถ้าเจอปัญหาให้ใส่เครื่องหมายคำพูด เช่น `"Y"`

ถ้าต้องยิงกลับไปคำนวณที่เซิร์ฟเวอร์ทุกครั้งจะหน่วง จึงส่งระยะห่างของทุกเส้นมาให้ครบตั้งแต่แรก

**ทำไมใช้ median ไม่ใช่ค่าเฉลี่ย** — ค่าเฉลี่ยจะถูกหุ้นตัวเดียวที่วิ่งแรงมากดึงจนเพี้ยน
เช่นกลุ่ม 10 ตัวที่ 9 ตัวนิ่ง แต่ NVDA +25% ค่าเฉลี่ยจะขึ้นไป +2.5% ทั้งที่ภาพรวมกลุ่มไม่ได้ดี
median ทนต่อค่าสุดขั้วแบบนี้

**หุ้นที่ประวัติไม่ครบ** — เช่นเพิ่งเข้าตลาด 3 เดือนแต่เลือกดูช่วง 1 ปี จะไม่ถูกนำมาแสดง
ไม่ใช่คำนวณจากข้อมูลเท่าที่มี เพราะจะทำให้ตัวเลขเทียบกันไม่ได้

## เวลาที่ระบบดึงข้อมูลเอง

**ทุกวันตอนตี 4 ครึ่งเวลาไทย** (เช้าวันอังคาร–เสาร์) · วันละ 1 รอบ

ตลาดสหรัฐปิด 16:00 ET ซึ่งตรงกับตี 3–4 เช้าวันถัดไปของไทย
ระบบจึงตั้งไว้ที่ **21:30 UTC วันจันทร์–ศุกร์** = ประมาณ 1 ชั่วโมงหลังตลาดปิด
ตรงกับตี 4 ครึ่งเช้าวันอังคาร–เสาร์บ้านเรา

พอตื่นเช้ามาเปิดดู ข้อมูลของคืนที่ผ่านมาพร้อมอยู่แล้ว

| ส่วน | ดึงบ่อยแค่ไหน |
|---|---|
| ราคาหุ้นรายวัน + EMA รายวัน | ทุกรอบ |
| P/E และมูลค่าบริษัท | คำนวณใหม่ทุกรอบจากราคาปิดล่าสุด |
| งบการเงิน (EPS, ROE, ปันผล) | ตัวที่เก่ากว่า 3 วัน สูงสุด 300 ตัวต่อรอบ |
| เส้น EMA รายสัปดาห์ | สัปดาห์ละครั้ง |

**อยากเปลี่ยนเวลา** แก้บรรทัด `cron` ใน `.github/workflows/build.yml`
รูปแบบคือ `"นาที ชั่วโมง * * วันในสัปดาห์"` โดย**เวลาเป็น UTC** (เวลาไทย = UTC + 7)

```yaml
- cron: "30 21 * * 1-5"    # ตี 4 ครึ่งไทย หลังตลาดปิด (ค่าปัจจุบัน)
- cron: "0 1 * * 2-6"      # 8 โมงเช้าไทย
- cron: "0 12 * * 2-6"     # 7 โมงเย็นไทย
```

หมายเหตุ: ถ้าตั้งเป็นเวลากลางคืนแบบปัจจุบัน วันในสัปดาห์ต้องใช้ `1-5` (จันทร์–ศุกร์ ตามเวลา UTC)
แต่ถ้าตั้งเป็นเวลาเช้าของไทย ต้องใช้ `2-6` เพราะข้ามวันไปแล้ว

หมายเหตุ: cron ของ GitHub รันตามคิว อาจคลาดเคลื่อนได้ 5–30 นาที

## แก้ปัญหาที่เจอบ่อย

**เว็บขึ้นว่าโหลดข้อมูลไม่สำเร็จ** — ยังไม่ได้กด Run workflow หรือ workflow ล้มเหลว
ไปดูที่แท็บ Actions

**Actions ขึ้นติ๊กแดง** — คลิกเข้าไปดูขั้นตอนที่มีเครื่องหมาย ✕
ส่วนใหญ่คือ Yahoo จำกัดการเรียก (rate limit) แก้ด้วยการกด **Re-run all jobs** อีกครั้ง
ถ้ายังไม่ผ่าน ลองใส่ `limit` เป็น `200` เพื่อลดจำนวนหุ้นลง

**ในหน้า Actions ขึ้นเตือน `ไม่อยู่ในดัชนีแล้ว จึงข้ามไป: XXX`** — เป็นการทำงานปกติ
หมายความว่าหุ้นตัวนั้นใน `themes.yml` หลุดจากดัชนีแล้ว หรือแหล่งข้อมูลใช้ชื่อย่ออื่น
(เช่น Fiserv เปลี่ยนจาก FISV เป็น FI) แก้ชื่อใน `themes.yml` หรือลบออก

**Pages ไม่มีตัวเลือก `/docs`** — โฟลเดอร์ `docs` ยังไม่ได้อัปขึ้นไป ตรวจที่แท็บ Code

**เว็บยังแสดงข้อมูลเก่า** — GitHub Pages ใช้เวลา 1–2 นาทีหลัง workflow เสร็จ
ลองรีเฟรชแบบล้างแคชด้วย `Ctrl + Shift + R`

**schedule หยุดทำงานเอง** — GitHub ปิด schedule ของ repo ที่ไม่มีการเคลื่อนไหวเกิน 60 วัน
เข้าไป commit อะไรก็ได้เพื่อปลุกกลับมา

## ข้อจำกัดที่ควรรู้

- **yfinance ไม่ใช่ API ทางการ** เป็นการดึงข้อมูลจากหน้าเว็บ Yahoo
  Yahoo เปลี่ยนอะไรเมื่อไหร่ก็อาจพังได้ ถ้าเจอบ่อยค่อยพิจารณาย้ายไป Alpaca หรือ Stooq
  โค้ดส่วนดึงข้อมูลอยู่ในฟังก์ชัน `fetch_prices()` ของ `build.py` ที่เดียว
- **รายชื่อ Nasdaq 100** ไม่มีไฟล์ทางการฟรี ใช้ชุดข้อมูลสาธารณะที่ดึงจาก Wikipedia
  อาจช้ากว่าประกาศจริงไม่กี่วัน มีแหล่งสำรองไว้ให้แล้ว
- **ตัวเลขพื้นฐานมาจาก Yahoo Finance** ซึ่งบางตัวอาจล้าสมัยหรือหายไปเป็นบางช่อง
  โดยเฉพาะบริษัทที่เพิ่งเข้าตลาดหรือขาดทุนอยู่ ถ้าตัวเลขไหนดูผิดปกติมาก ควรตรวจกับแหล่งอื่นก่อน
- **ไม่มีข่าว** — การดึงข่าวต้องยิงทีละตัว 561 ครั้งต่อวัน เสี่ยงทำให้โดน Yahoo บล็อกทั้งระบบ
  และการแปลเป็นไทยต้องใช้บริการที่เสียเงิน จึงเลือกไม่ทำแทนที่จะทำแบบไม่น่าเชื่อถือ
- ยังไม่มี Watchlist ส่วนตัว (บันทึกหุ้นที่สนใจไว้)
